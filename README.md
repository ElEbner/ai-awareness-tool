# ai-awareness-tool

[![DOI](https://zenodo.org/badge/1293670354.svg)](https://doi.org/10.5281/zenodo.23498081)

A simple HTML based tool for raising awareness on data protection, legal and ethic issues when using AI tools for research data processing.

The user is asked to answer two questions about the data types in a research project and the intended tasks for data processing. Based on these, recommendations (awareness points) for the selected data types and use cases are presented, with reference to relevant guidelines from publishers, Norwegian research institutions and the European Commission, as well as to European law and research ethics frameworks.

This tool is a prototype, and needs to be adjusted to relevant frameworks, policies and guidelines at the institution it is supposed to be used. The recommendations in this tool are meant as a starting point, researchers are encouraged to seek out further guidance on specific issues. 
The included data types and use cases do not represent a comprehensive overview, but a selection based on what was considered most common. 

The code was created by prompting Claude (Sonett 4.6, May 2026) to create an initial draft, resulting in HTML file with embedded CSS and JS. The initial categories for data types and use cases were adjusted according to literature referenced in the HTML file, and the results page was altered with content from guidelines, legal texts and other relevant sources.
